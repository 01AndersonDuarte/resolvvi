# Frontend

Interface web em React 19, TypeScript, Vite e Tailwind CSS. Durante o desenvolvimento, o Vite encaminha as chamadas `/api` ao backend conforme `VITE_API_PROXY_TARGET`.

Consulte o [README da raiz](../README.md) para requisitos, configuração dos ambientes, execução via Docker Compose ou local e comandos de testes.

Comandos principais executados dentro de `frontend/`:

```bash
npm ci
npm run dev
npm test
npm run test:coverage
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```
